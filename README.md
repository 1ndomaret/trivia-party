# 🎯 Real-Time Multiplayer Trivia App

> ⚠️ **WORK IN PROGRESS**: This project is currently under active development and is not yet ready for use or deployment.

A real-time multiplayer trivia application built with a high-performance **Go** backend and a cross-platform **React Native** mobile frontend.

---

## 🛠️ Current Tech Stack

- **Frontend:** React Native (Expo Router, NativeWind)
- **Backend:** Go (Gorilla WebSockets, GORM)
- **Database:** PostgreSQL
